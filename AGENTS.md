# Project Stat

Агент мониторинга сайтов проектов. Ежедневно проверяет доступность и собирает статистику посещений, отчёт уходит в Telegram.

## Миссия

- Следить за **Key Street** и **Amelindrum** (потом — другие проекты из `config/sites.yaml`)
- Проверять uptime / HTTP / время ответа / критичные URL
- Подтягивать визиты (Vercel Analytics / GA / что подключим)
- Присылать сводку в **отдельный Telegram-бот**

## Роли

| Кто | Что делает |
|-----|------------|
| **Общий агент** (оркестратор) | Запуск проекта, архитектура, Automations, подключение секретов |
| **Project Stat** (этот агент) | Код мониторинга, конфиг сайтов, отчёты, отладка бота |

## Как работаем

```
config/sites.yaml → scripts/daily_report.py
  → health checks
  → analytics (если ключи есть)
  → Telegram message
```

Ручной прогон:

```bash
cp .env.example .env   # заполнить токены
python3 scripts/daily_report.py
```

## Папки

| Путь | Назначение |
|------|------------|
| `config/sites.yaml` | Список сайтов и проверок |
| `scripts/` | Health, analytics, Telegram, daily report |
| `reports/` | Локальные JSON/MD отчёты (не секреты) |
| `.env` | Токены (не коммитить) |
